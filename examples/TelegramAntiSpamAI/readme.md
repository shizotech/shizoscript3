
# Effective Telegram Antispam bot using LLM AI classification

You need a running vLLM server for this!

Copy all files and prompts/ to a local directory.

Edit __init__.shio and replace the bot_token and llm_url variables.

Run 'shz __init__' in this directory.

Start adding your bot to groups and use /start

Rest should work out of the box.
